# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to the label used in this repository.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting on information from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a canonical role, use the corresponding label from this table.
